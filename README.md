# CQB Training Suite — MVP

Web dual-view trainer: instructor top-down + trainee first person.

## Run
Serve the folder (modules will not load from file://):

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Controls
- Click first-person canvas, then mouse look
- WASD move
- Instructor: pause, reset, drop civilian, reclassify unknown
