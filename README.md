# CQB Training Suite

Graduation demo. Training only. Not a shooter. Not a method for assault.

## Open

1. `index.html` — home
2. `aar.html` — Nimrod AAR replay (public record, 1980 London embassy)
3. `train.html` — apartment drill (WASD + mouse)

Use a local server if the drill is blank:

```
python3 -m http.server 8080
```

Then open http://localhost:8080

Green = hostage / civilian. Red = unknown. Identify before you act.
